Forum CachyOS: come proteggere KDE Plasma dagli attacchi tramite notifiche dei file

Un utente segnala una mitigazione semplice, prevista dalla documentazione KDE, contro lo spionaggio della tastiera e le finestre di password false.

Il 4 ottobre sul forum ufficiale di CachyOS è stata rilanciata la documentazione KDE sui cosiddetti 'File Notification Attacks': un programma malevolo può osservare gli eventi di accesso ai dispositivi di input (/dev/input) per dedurre quando si premono i tasti, oppure sovrapporre una finestra fasulla a quella di richiesta password.

Per verificare se il proprio kernel è già protetto si può usare il comando inotifywait -m -e access,modify /dev/input (pacchetto inotify-tools): se premendo i tasti non compaiono notifiche, la mitigazione è presente. Diversi utenti ricordano che con i kernel di quest'anno gran parte del problema è già stato corretto a monte.

La contromisura lato desktop consiste nel creare una regola di finestra in KDE per la finestra di autenticazione Polkit: impostare 'Mantieni sopra le altre' su Forza/Sì e attivare la massima prevenzione del furto del focus. Così nessun'altra finestra può coprire la richiesta di password, che resta sempre riconoscibile.

L'unico effetto collaterale è che non si possono aprire finestre sopra il dialogo Polkit. Si tratta di un consiglio della comunità, non di un avviso ufficiale del team CachyOS.
